InsightView · AI Agent 是否会颠覆 SaaS

主题阅读综合报告 · Salesforce 为在位者转型案例
InsightView · 主题报告 · By Claude Sonnet 4.5 · 2026-08-09
📌 核心观点
推 1 · 核心结论

AI Agent 不是在颠覆某一家 SaaS 公司，而是在颠覆 SaaS 行业二十年来赖以生存的按席位收费模式。

Gartner 将这个机制命名为"智能体套利"（Agentic Arbitrage）：Agent 跨系统完成任务，绕过传统 UI，让软件变得"隐形"——用户增长与营收增长之间的绑定关系被切断。

Salesforce 自称"AI Agent 公司"恰恰说明问题：在位者不是被 Agent 颠覆的对象，而是被迫自我颠覆的样本。真正的威胁不是 Agent 消灭 SaaS，而是 SaaS 的商业模式必须从"人头税"切换为"任务税"。

📎 来源：01, 21, 22, 26

推 2 · 一句话判断

3-5 年内，AI Agent 不会消灭 SaaS，但会将 SaaS 行业一分为二。

薄封装工具（workflow wrapper）会被 Agent 吞噬，拥有专有数据的系统记录（system of record）反而因 Agent 而增值。

Gartner 预测：到 2030 年，35% 的单点 SaaS 工具将被 Agent 替代或吸收。席位定价占比将从 21% 降至 15%，至少 40% 的 SaaS 支出转向消费制/结果制定价。

📎 来源：21, 23, 26

🏢 主题简介
推 3 · SaaSpocalypse：2 万亿美元蒸发

2026 年 2 月 3 日，被华尔街称为"Black Tuesday for Software"。S&P 500 软件指数单日暴跌 13%，创历史最大单日跌幅。

48 小时内约 $2850 亿市值蒸发，六周内 damage 扩大到$2 万亿。Salesforce 跌约 38%，HubSpot 跌 51%，ServiceNow 跌 28%，Workday 跌 22%，Adobe 市值蒸发 $1200 亿。

导火索不是财报暴雷——是 Anthropic 发布 Claude Cowork 和 OpenAI 发布 Frontier 平台后，市场第一次"看见"AI Agent 可以替代整个 SaaS 品类的人类操作者。

📎 来源：14, 16, 17

推 4 · 核心矛盾：Agent 不需要"席位"

SaaS 二十年的增长引擎是一个极简公式：更多员工 = 更多软件席位 = 更多订阅收入。

Salesforce 靠这个模型做到 $415 亿年收入，ServiceNow $110 亿，Workday $80 亿。但 AI Agent 不登录系统、不点菜单、不产生席位费——它直接调 API 完成工作。

一个 Agent 可替代 10-15 个中层员工的管理工作量。企业从 500 个许可证砍到 50 个就能维持同等产出——这是 90% 的席位压缩。

Gartner 预测 2025 年仅 <5% 企业应用内置 Agent，到 2026 年底将达40%。

📎 来源：18, 19, 04

推 5 · "智能体套利"：Gartner 的正式定义

2026 年 7 月，Gartner 发布正式研报，将这一趋势命名为"Agentic Arbitrage"（智能体套利）。

Gartner 副总裁 Brocklehurst 的原话："Agent 系统直接交付业务结果，绕过重度依赖 UX 的传统应用，让软件变得'隐形'。" 到 2030 年约 $2340 亿企业应用支出暴露于智能体套利，占 SaaS 总支出的约 20%。

但 Gartner 同时警告：超过 40% 的 Agent AI 项目将在 2027 年底前被取消。真正在构建 Agent 能力的厂商只有约 130 家，其余都是"Agent 洗"（agent washing）。

📎 来源：21, 22, 25

📦 SaaS 行业战略应对
推 6 · 在位者的三条反击路线

SaaS 在位者正在沿三条路线反击。

① 自建 Agent 平台——Salesforce Agentforce（$12 亿 ARR）、ServiceNow Now Assist、微软 Copilot（1600 万付费席位，YoY +160%）。把 Agent 变成自己生态的一部分，而非被外部 Agent 绕过。

② 定价模式从"按人头"转向"按结果"——高盛将这一趋势命名为 RaaS。ServiceNow 一半净新增业务已通过非席位定价达成。Zendesk 成为 CX 行业第一个正式推出结果制定价的公司。

③ 成为 AI 治理层——掌握企业数据的平台不卖工具，卖"可信的 Agent 运行环境"。Salesforce 收购 Informatica（$80 亿）补齐数据治理。

📎 来源：18, 21, 05

推 7 · Salesforce：自我颠覆的样本

Benioff 在 Dreamforce 2025 上宣布："Salesforce 不再是一家 CRM 公司，而是一家 AI Agent 公司"。这是公司 27 年历史上最激进的身份重构。

核心赌注是 AWU（Agentic Work Units） 消费制定价：每次 Agent 自主完成任务计为一个 AWU，标准对话 $2/次，自主操作 $0.10/次。

截至 FY2026 Q1，Agentforce ARR 达 $12 亿（YoY +205%），签署 29,000 份协议。

📎 来源：05, 06, 08

推 8 · 三种定价模型的摇摆

Salesforce 在 18 个月内经历了三种定价模型的摇摆——从 $2/对话到 Flex Credits $0.10/操作再到 $125/用户/月的席位附加包。

这种混乱不是战略连贯性，而是市场真实不确定性的映射。高 volume 客户的消费账单已出现超预期案例——客户开始逃离而非追加。

Q4 营收 $112 亿（YoY +12%），但总营收增速已降至 10%，AI 相关收入占比仍不足 7%。一个销售工程师报告：90 个企业账户中人类 CRM 席位已减少 10%。

📎 来源：06, 07, 09

推 9 · ServiceNow、HubSpot、Zendesk：各自的转身

ServiceNow（$110 亿收入，增速 22%）走"混合定价"路线——基础席位许可 + token/连接器消费制。CEO 直言 agentic AI"不是革命，是唯一活下去的方式"。

一半净新增业务已通过非席位定价达成，Now Assist ACV 从 $10 亿上调至 $15 亿。30-40% IT 工单可无人干预解决。

HubSpot（增速 19%）推出结果制定价：AI 全自主解决客户咨询才收费，附带 28 天免费试用。Zendesk 是最干净的结构性赌注——CX 行业第一个正式结果制定价。

📎 来源：18

推 10 · AI-native 挑战者：没有历史包袱的降维打击

真正的威胁是AI-native 原生创业公司——它们从第一天就按 Agent 架构设计，没有 20-25 年的历史包袱。83% 的 AI-native SaaS 公司已提供消费制定价。

Rox AI（红杉领投 $5000 万）直接杀入 CRM 腹地：Agent 端到端执行从数据分析到邮件发送的全流程，不需要人类操作 CRM 界面。

11x.ai 的 Alice 和 Artisan 的 Ava 已能 24/7 自主完成 SDR 全流程。Coffee 以"AI-first CRM"定位，消除 64% 手工录入。

新创业公司的最大优势不是技术——是没有遗留定价架构需要迁移。

📎 来源：10, 11, 12, 13

推 11 · Bret Taylor：Agent 是企业软件的新原子单位

Salesforce 前联席 CEO、OpenAI 董事会主席、Sierra 创始人 Bret Taylor 提出："Agent 是企业软件的新原子单位"，就像网站定义了互联网时代、App 定义了移动时代。

未来的 Agent 不会是通用型工具，而是垂直领域的深度专家。他在 Sierra 实践 RaaS——客户不为软件许可付费，而是为 Agent 完成的业务结果付费。

他直言"按 token 计费大错特错"，因为客户不关心你消耗了多少算力，只关心结果。模型会像数据库一样商品化，真正的差异化在业务流程而非技术栈。

📎 来源：38, 39, 40

推 12 · Sierra 的商业验证

Sierra 在 2026 年 5 月完成 $9.5 亿融资，估值 $158 亿。ARR 7 个季度从 0 到 $1.5 亿，覆盖 40%+ Fortune 50。

Taylor 预测："3-4 年内消费者会更偏好使用 AI Agent 的企业"。Sierra 还收购了 TakeOff 长程 Agent 平台，补齐多步推理能力。

Sierra 的存在本身就是一个信号：前 Salesforce 联席 CEO 选择从零构建 Agent 原生公司，而不是在 Salesforce 内部改造。

📎 来源：40, 51, 52

🧩 产品战略
推 13 · Agentforce 产品演化 Timeline

从被嘲笑的"Clippy 2.0"到 $12 亿 ARR 的数字劳动力平台，Salesforce 用 18 个月完成了三次产品范式跳跃。

这是 SaaS 在位者产品转型的典型路径——从 UI 补丁到推理引擎再到数字劳动力平台。

📎 来源：05, 06, 07, 08

推 14 · Headless 化：SaaS 从"给人看"到"给 Agent 用"

2026 年 4 月，Salesforce 发布Headless 360——将核心 CRM 能力暴露为 API、CLI 和 MCP 工具，Agent 可以不经过传统 UI 直接操作。

Box CEO Aaron Levie 的判断："如果功能只存在于 GUI 中，对 Agent 来说等于不存在。"

这标志着 SaaS 行业承认了一个事实：Agent 时代的用户不是人，是 Agent。Agent 不参加 Webinar、不看广告、不回应 onboarding 流程——它只使用最容易集成、最适合任务的工具。

📎 来源：08, 48, 49

推 15 · Aaron Levie：Agent 用软件的频率是人的 100 倍

Box CEO Aaron Levie 提出反直觉论点："AI Agent 不会杀死企业软件，而是把它变成高吞吐量基础设施"。

CRM 记录、企业文档、分析系统——这些在人类时代因为"懒得查"而使用率极低的系统，一旦 Agent 可以无摩擦地 7×24 查询，调用量会暴增 100 倍。

他改写了 Paul Graham 的名言："Make something agents want." 预期企业最终会为每个员工运行数百甚至数千个 Agent。

代价是：传统权限模型为人设计（角色+会话+界面），Agent 时代需要全新的最小权限、操作审批、审计回滚机制。

📎 来源：48, 49

推 16 · 分水岭：Workflow Wrapper vs System of Record

SaaS 世界正在被一条简单的分界线切成两半。

薄封装工具（Workflow Wrapper）会死——价值在于工作流而非数据的工具（状态推送、通知规则、审批流程、智能分配），Agent 可以重建这些工作流。Gainsight、Outreach、Gong 这类工具面临真威胁。

系统记录（System of Record）会活——拥有不可替代专有数据的平台（会计账本、CRM 客户历史、资产管理记录、合规审计日志），Agent 不替代它，而是成为它最好的客户。

判断标准只有一个：如果工具的价值是工作流，Agent 能重建；如果价值是数据，Agent 成为它最频繁的用户。

📎 来源：23, 24

推 17 · 数据护城河：AI 越强，数据越值钱

一个被忽视的逻辑："AI 越能取代工作，掌握数据的 SaaS 就越有价值"——因为 Agent 需要数据才能工作，而数据在系统记录手里。44% 的组织将数据质量列为 AI 应用最大障碍。

Salesforce 的赌注是 Data Cloud + $80 亿收购 Informatica——补齐数据治理和 MDM，确保 Agent 工作在可信、合规的数据之上。

谁掌握最干净的企业数据，谁的 Agent 就最可靠——这比模型能力本身更难被颠覆。

📎 来源：26, 27, 13

推 18 · 反方：Agent 杀不死有数据的 SaaS

富途研究指出：被抛售的龙头企业基本面仍强韧——ServiceNow 收入增速 22%，Salesforce 营收 $415 亿，HubSpot 增速 19%。行业并非崩溃。

Gartner 也明确表示："SaaS 不会消亡，而是以全新形态发展。"

关键区分：没有独家数据的"薄封装工具"面临真威胁；但深度嵌入核心业务流程、掌握不可替代专有数据的平台，反而因 Agent 的存在而增值。

📎 来源：26, 27, 28

推 19 · Sam Altman：SaaS 已死，Service as a Software 到来

OpenAI CEO Sam Altman 多次预言："SaaS 已死，服务即软件到来"。如果任何软件都可以即时生成，你不再需要"购买"某家 SaaS 公司的产品。

他的判断更激进：Agent 不需要官方 API 就能接入任何服务——通过浏览器自动化、表单填写、屏幕读取，Agent 可以像人类一样操作任何软件。

"权限经济"已死——过去 SaaS 靠控制访问入口收过路费，现在 Agent 直接穿墙。

📎 来源：42, 53, 41

推 20 · "每家公司都是 API 公司" + 终局判断

Altman 在 Cisco AI Summit 上说："Every company is an API company now, whether they want to be or not."

他划了一条生死线：拥有强核心系统+专有数据+网络效应的在位者能活，只有"薄封装层"的 SaaS 会死。CRM 数据、合规历史、客户基数是"城堡"；仪表盘和菜单是"沙堡"。

Altman 和 Bret Taylor 不约而同指向同一个终局：从"Software as a Service"到"Service as a Software"——AI 不再是帮人构建软件的工具，而是直接提供完整的服务结果。

终局可能是"Agent 就是 CRM"——不需要人参与，Agent 直接完成销售、服务、分析的完整闭环。Salesforce 的 Agentforce 目前仍是"让 Agent 帮人用 CRM"，离这个终局还有距离。

📎 来源：42, 53, 22

🏗️ 组织文化
推 21 · 在位者的自我清洗：用 Agent 替代自己的员工

Benioff 宣布 2026 财年不再招聘新工程师——AI 工具已为开发工作带来 30%+ 效率提升。客户支持团队从 9,000 人缩减至 5,000 人。

这不是裁员公告，是战略信号：公司在用 Agent 替代自己的员工，然后再把这个能力卖给客户。

2025 年科技公司裁员 245,000 人（783 家公司，平均每天 674 人），月度新增岗位从 168,000 暴跌至 49,000，降幅 71%。

核心逻辑是：先用 Agent 优化自己，再把 Agent 能力产品化。Benioff 在达沃斯说："从现在起，我们管理的不仅是人类员工，还有数字员工。"

📎 来源：09, 14, 32

推 22 · 黄仁勋：我们在创造劳动力，不是工具

NVIDIA CEO 黄仁勋定义了 Agent 时代的经济底层："全球 IT 产业 1 万亿美元，全球经济 100 万亿美元——我们面对百倍市场"。

Token 成为新的大宗商品，NVIDIA 预计到 2027 年数据中心基础设施需求达$1 万亿。

关于就业："AI 取代工作是完全无稽之谈"。如果每个软件工程师能产生 $9 万亿的生产力，企业会想招更多人而非更少。100% 的 NVIDIA 工程师正在使用 Claude Code、Codex 或 Cursor。

对 SaaS 行业的信号：没有 Agent 能力的 SaaS，会被有 Agent 能力的 SaaS 淘汰。

📎 来源：50, 54

推 23 · Medallia 警示：席位依赖的致命后果

2026 年 4 月 22 日，Thoma Bravo 将 Medallia 的所有权转移给债权人，约 $51 亿股权归零。

席位压缩不是唯一原因，但收入与客户人头数绑定的模型失去了偿债所需的增长缓冲。

这对所有高杠杆 SaaS 公司是直接警告：如果你的收入模型是席位制，且背着大量债务，Agent 带来的席位压缩不是战略问题——是偿债能力问题。

更隐蔽的风险是"幽灵席位"（ghost seats）——AI 已吸收工作流但合同未重新谈判的付费许可证。

📎 来源：16, 18

推 24 · 客户落地的真实差距

Williams-Sonoma 的 AI 助手 Olive 预期自主解决 60%+ 聊天咨询——但部分标杆案例仍在"开发中"。

Salesforce 客户满意度 2025 年下降超 15%，一线员工对 AI 工具支持率仅 30%。企业自建 AI Agent 的平均准确率仅 52%——大多数 DIY 项目永远停留在试点阶段。

平台型产品平均 75%+，部署速度快 16 倍。但这个差距会随模型能力提升而收窄。

方向是对的，但节奏被严重高估。

📎 来源：30, 16, 21

推 25 · Benioff 的反泡沫论："太快了"

Benioff 反复强调一个词："too soon"——技术能力的跃迁和商业模式的瓦解之间，往往隔着好几年。

企业迁移系统的成本、合规风险、组织惰性，远比模型能力的进步慢得多。57% 的组织将 21-50% 数字化转型预算投入 AI 自动化，但落地精度和治理远未成熟。

"SaaS 不会一夜消失，Agent 也不会一年内接管企业世界"——方向可能是对的，但节奏几乎一定被高估了。

这对在位者是好消息：转型有时间窗口，但窗口不会永远开着。

📎 来源：30, 21, 25

推 26 · Benioff（X）："The software bears are dead wrong"

2026 年 4 月 20 日，Benioff 在 X 上直接反击做空者："The software bears are dead wrong."

Pearson 的 Agentforce 将无需人工干预解决的客户问题比例提升 40%；PenFed 用 Agent 处理密码重置和账户解锁，IT 工单总量下降 40%。

他造了一个新词："Agenticware, not Software"——不是修辞，是品牌层面的身份切割。

同期 Q4 营收 $112 亿（YoY +12%），Agentforce ARR 达 $8 亿（YoY +169%），$500 亿回购。用真金白银回应市场恐慌。

📎 来源：43, 44

推 27 · Benioff vs Nadella："Clippy 2.0" 公开互撕

2025-2026 年科技界最公开的 CEO 级口水战。Nadella 宣称："我们所知的 SaaS 时代即将结束"，SaaS 本质只是"CRUD 数据库加业务逻辑"。

Benioff 的回击是直接人身级嘲讽——多次称微软 Copilot 为"Clippy 2.0"："根本不起作用，没有任何准确性。"

两条技术路线的本质分歧：Nadella 押注"Agent Stack 替代 App Stack"——Agent 成为操作系统级调度层，SaaS 退化为数据库后端。

Benioff 押注"Agent 嵌入业务流程"——Agent 深度绑定数据和工作流，不颠覆 SaaS 而是让 SaaS 更关键。

📎 来源：45, 15

推 28 · Nadella（X）："逆向信息悖论" + "保持相关"

Nadella 提出"逆向信息悖论"——企业使用 AI 时不只付钱获取智能，还在不经意间交出自己的知识。

每次员工与 AI 交互——提示词、纠错、评估方法——都在生成"智能废气"，被 AI 厂商收集后用于改进模型，企业反而丧失了差异化知识。

他的另一句话可以概括所有在位者的焦虑："Success is not about longevity. It's about relevance."

对 SaaS 行业的映射：掌握数据主权的平台，不仅不被 Agent 颠覆，反而成为"AI 记忆"的守护者。

📎 来源：46, 47

推 29 · "Agent 洗"：颠覆是真的，泡沫也是真的

Gartner 警告：真正在构建 Agent 能力的厂商只有约 130 家，其余都是"Agent 洗"（agent washing）。

超过 40% 的 Agent AI 项目将在 2027 年底前被取消——原因是成本失控、价值不明、治理薄弱。

这与 SaaSpocalypse 的恐慌形成微妙对照：市场既高估了 Agent 短期颠覆 SaaS 的速度，也低估了 Agent 长期重塑 SaaS 商业模式的深度。

推 30 · 战略维度：自我颠覆 vs 被颠覆

SaaS 行业的生死不在于产品是否被淘汰，而在于能否在 Agent 时代重新定义自己的价值层。

Benioff 选择了最难但最正确的路——主动摧毁 per-seat 模式，用 AWU 消费制替代。ServiceNow 走混合定价，Zendesk 直接跳到结果制。

但风险在于：Agent 消费收入能否跑赢席位收入下滑？一个 Salesforce 销售工程师报告：90 个企业账户中人类 CRM 席位已减少 10%。乘以 150,000 客户，数学令人不安。

推 31 · 产品维度：数据护城河 vs 架构劣势

正方：掌握专有数据的 SaaS 平台——Salesforce 的 CRM 数据、Workday 的 HR 数据、ServiceNow 的 IT 工单数据——是AI-native 创业公司无法速成的基础设施。Agent 越强，这些数据越值钱。

反方：在位者背着 20-25 年的历史架构包袱。AI 功能是"螺栓固定"而非"原生设计"，数据需要 3-6 个月清洗才能让 Agent 正常工作。

AI 编程工具把"自建 CRM"的成本降到十分之一——"自建"与"购买"的交叉点已到。Netlify CEO 已公开用 AI 替代 $50/月的 SaaS 调查工具和报价工具。

关键变量：Headless 化能否真正把旧架构"翻转"为 Agent 原生。如果翻转够快，在位者变成"Agent 时代的数据基础设施"；如果不够快，就被 AI-native 挑战者从侧面绕过。

推 33 · 终局：SaaS 不会死，但 SaaS 的"卖法"会死

把所有线索放在一起，终局画面逐渐清晰：SaaS 作为软件形态不会消亡，但按席位订阅的商业模式正在走向终结。
